# Mabobot v3.0.1：yt-dlp 迁移可靠性修复

本版修复 Summary Plus 在项目目录改名、移动或从备份恢复后，视频下载器可能立即退出的问题。

## 修复内容

- Bilibili、抖音、小红书、微博、虎扑及本地 ASR 的 yt-dlp 调用统一绑定到当前 Python 环境。
- 不再执行可能残留旧绝对路径的 `yt-dlp.exe`，改用 `python -m yt_dlp`。
- Web 控制台的 yt-dlp 升级后验证与实际运行方式保持一致。
- 失败日志增加调用命令、stdout 和 stderr，便于排查环境与站点变化。

## 升级

更新全部源码后，通过根目录 `START.bat` 完整重启 Mabobot。无需手动重建虚拟环境，也无需重新安装 yt-dlp。
