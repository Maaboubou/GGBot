# Mabobot v3.0.1：修复全新安装的 Win32 依赖

Mabobot 3.0.1 修复 3.0.0 在干净 Windows 环境首次安装后可能缺少 `pywin32`，导致微信 Bot 报错 `No module named 'win32api'` 并持续重启的问题。

## 修复内容

- `requirements.txt` 显式声明 Windows 平台的 `pywin32` 依赖。
- 首次安装、重复启动和环境修复都会验证 `mabowx` 实际使用的 Win32 模块。
- 依赖标记存在但 Win32 模块缺失时，启动引导会自动进入安装流程，而不是继续启动故障服务。
- `mabowx.env_check` 覆盖窗口、进程、互斥锁、安全令牌、会话及截图所需模块。

## 升级

更新源码后完全退出 Mabobot，再运行根目录的 `START.bat`。依赖清单哈希发生变化后，启动器会自动安装缺失依赖。

如仍在使用 3.0.0，也可以先临时执行：

```powershell
.\.venv\Scripts\python.exe -m pip install pywin32
```

完成后重新运行 `START.bat`。
