# Mabobot v3.0.2：首次安装可观测性与微信可靠性

本版重点改善全新 Windows 环境的首次启动体验，并加强微信掉线恢复、消息接收和媒体下载链路的可靠性。

## 首次安装

- 无需预先安装 Python。缺少 64 位 Python 3.11/3.12 或 Microsoft WebView2 Runtime 时，`START.bat` 会列出组件、征得确认并从官方源下载安装。
- 安装窗口显示阶段百分比、Chromium 下载进度、实时命令输出、已用时间、最后活动时间和安装进程 PID。
- 连续 60 秒无新活动时显示警示，连续 5 分钟无新活动时明确提示可能卡住。
- 可直接查看实时日志；取消或关闭安装窗口时，会确认并结束本次 PowerShell、Python 与 Playwright 子进程树。
- 如果旧版安装窗口已经关闭但后台进程仍在运行，再次执行 `START.bat` 可识别并清理对应项目的残留进程，然后立即重新启动。

## 微信可靠性

- 微信掉线后自动进入重新登录流程；需要扫码时可通过已配置邮箱发送内嵌登录二维码，恢复在线后发送恢复通知。
- 改进消息页重叠识别、UI 锚点恢复和监听同步，降低翻页、控件虚拟化及微信重连时的漏消息风险。
- 图片下载增加消息身份校验、明确的可重试错误和审计信息，避免错误图片被绑定到当前消息。
- 本机内部 HTTP 通信强制绕过系统代理，并修正非零视口原点下的 Win32 坐标换算。

## 配置与维护

- 官方登录模式的 Codex Profile 可重新选择当前 ChatGPT 账号支持的模型，并同步推理强度、上下文窗口与能力信息。

## 升级

使用 Git 安装的用户在项目目录执行 `git pull`，然后完整退出并重新运行 `START.bat`。通过 ZIP 安装的用户请下载并完整解压本版本源码后运行 `START.bat`。

如果旧安装仍在后台，新版启动器会显示恢复提示；选择结束旧进程并重新开始即可。
