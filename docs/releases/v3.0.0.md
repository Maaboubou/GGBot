# Mabobot v3.0.0：mabowx 与统一桌面体验

Mabobot 3.0.0 以当前新版为唯一公开基线：微信 UI 自动化已迁移到内置 `mabowx`，并提供统一桌面启动器、Web 控制台和 Codex 助手运行中心。

## 安装与启动

准备 Windows 10/11、微信 4.1、64 位 Python 3.11 或 3.12。下载并完整解压源码后，运行根目录的 `START.bat`；首次启动会自动创建环境并安装依赖。

如需 Codex 助手，请在 WSL 中安装 Codex CLI 运行框架，再到 Web 控制台创建 Profile。Profile 可以使用 ChatGPT 账号认证，也可以配置第三方 Responses 兼容模型，无需必须登录官方账号。

## 当前公开插件

- 聊天记录
- Magnet Check
- 菜单翻译
- Summary Plus
- Weekly
- 中国银行汇率

其余业务插件不包含在公开发行版中。

## 本版重点

- 统一的桌面窗口负责服务启停、重启、实时日志、环境检查、登录启动和系统托盘。
- `mabowx` 负责微信窗口、监听、读取与发送；应用层负责业务编排、权限和持久化。
- Codex 支持 Profile、Skill、模型路由、会话连续性以及按聊天隔离的文件处理。
- Windows 依赖显式包含 `pywin32`，安装器会验证所需 Win32 模块。
- WSL 管理脚本输出统一使用 UTF-8，不受 Windows 默认 GBK 编码影响。
- 新建 Profile 时会先解析当前 Linux/WSL 环境中的 Codex CLI 绝对路径，兼容由 PATH 提供的 `codex` 命令。

## 升级提示

这是破坏性升级。升级前请备份 `.env`、数据库和重要下载文件；更新全部源码后通过 `START.bat` 完整重启，不要混用旧版本文件。
