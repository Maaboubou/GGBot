# GGBot 微信自动化助手（公开精简版）

这是一个运行在 Windows 上的本地微信自动化控制台。公开版只保留聊天记录、翻译助手、汇率查询、周报助手、磁链检查、菜单翻译和完整 AI 助手。

默认不包含任何模型、API Key、聊天数据或个人配置。AI 长期记忆功能保留，但首次启动默认关闭。

当前版本包含可靠的微信文本发送链路：同一请求会去重，失败时只在明确未发送的情况下进行一次受控重试，并记录各阶段耗时，便于在运维日志中排查。

## 运行要求

- Windows 10/11，且有可交互的桌面会话。
- 微信 4.1 客户端已经安装并登录。
- 64 位 Python 3.11 或 3.12；安装 Python 时勾选 `Add Python to PATH`。
- `wxautox4` 可能需要单独购买并激活授权。
- 菜单翻译需要本机安装 Chrome；Selenium 会自动创建临时 Profile，无需手工配置，首次使用可能需要联网获取匹配的驱动。
- 周报助手需要另行安装、登录并配置 Codex CLI；不使用周报时可以暂不安装。

## 一键安装与启动

下载并解压后，直接双击：

```text
一键启动.bat
```

首次运行会自动：

1. 查找 Python 3.11/3.12。
2. 创建项目内的 `.venv`。
3. 安装 `requirements.txt`，包括经过当前版本验证的 `wxautox4`。
4. 从 `.env.example` 创建本地 `.env`。
5. 启动微信桥接和 Web 服务，并打开 <http://127.0.0.1:8888/>。

以后再次双击会复用现有环境；只有依赖文件改变时才重新安装。如果只想安装而不启动，可以运行 `Install.bat`。

## 首次配置

### 1. 激活 wxautox4

如果你的授权需要激活，请按照供应商提供的方式执行。常见形式为：

```powershell
.\.venv\Scripts\wxautox4.exe -a <你的激活码>
```

不要把激活码提交到 Git。

### 2. 添加 AI 模型

启动后打开“模型与调用 → 模型连接”，自行添加模型；公开版不会自动创建任何模型。添加时只需填写一个 API Key，每个模型的凭据彼此独立并保存在本机数据库，管理页面不会回显原始密钥。然后为需要的任务设置映射，例如：

- `builtin_chatbot.chat`：聊天回复
- `builtin_chatbot.judge`：主动回复判断
- `builtin_chatbot.ocr`：图片理解
- `builtin_translation.translate`：翻译
- `menu_translator.vision`：菜单识别

没有模型时，微信桥接、聊天记录、汇率和磁链检查等非 AI 功能仍可使用。

### 3. 分配聊天权限

在 Web 控制台“聊天”页面添加需要监听的群聊或联系人，并为其启用对应插件。AI 长期记忆全局默认关闭；需要时再到“AI 助手”中手动开启。

## 环境变量

`.env.example` 只提供空白模板。安装器首次运行会复制为 `.env`，以后不会覆盖你的修改。AI 供应商的 API Key 推荐直接在“模型连接”页面填写；如果已经在 `.env` 中提供对应变量，页面会自动识别，无需重复填写。

常用字段：

| 字段 | 用途 |
|---|---|
| `WECHAT_BOT_NAME` | 机器人在聊天中的显示名称 |
| `WEB_PORT` | Web 控制台端口，默认 8888 |
| `WX_BOT_PORT` | 微信桥接端口，默认 5555 |
| `*_API_KEY` | 对应 AI 供应商的本地凭据 |
| `CODEX_PROXY_USE_WSL` | Codex 位于 WSL 时为 `true`，原生 Windows 时为 `false` |
| `QQEMAIL_ADDR` / `QQEMAIL_CODE` | 可选的掉线邮件通知 |

## 数据与安全

控制台默认只监听 `127.0.0.1`，不要直接暴露到公网。本地数据库、聊天记录、模型配置、记忆库、日志和插件报告都保存在忽略目录中，不应提交到 Git。

如果需要重新生成全新本地状态，请先退出启动器，再自行备份并移走 `data/`；不要在程序运行时直接删除数据库。

更多说明见 [模型配置](docs/MODEL_CONFIGURATION.md)、[记忆管理](docs/MEMORY_LIBRARY.md) 和 [安全策略](SECURITY.md)。
