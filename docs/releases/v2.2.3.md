# Mabobot v2.2.3：窗口自动恢复、可靠发送与备份增强

本版本用已经在 Windows 现场验证有效的原生窗口几何修复，替换此前复杂但无法解决实际问题的“假活”巡检与重建链路。同时补齐监听缺失恢复、真实群聊 `@` 发送和备份迁移能力。

## 1. 独立聊天窗口自动恢复

- 每 5 秒用一次轻量 `EnumWindows` 扫描读取微信顶层窗口，不执行周期性 UIA 探测。
- 只把“窗口并未最小化，但当前位置与恢复位置都落入 Windows `-32000` 哨兵坐标”的窗口判为异常。
- 同一 HWND 必须连续命中两次才修复，默认恢复延迟为 5–10 秒。
- 修复仅更新 `WINDOWPLACEMENT` 和窗口位置，不抢前台、不置顶、不关闭也不重建聊天窗口。
- 正常最小化窗口、标题不唯一、PID 或窗口类别变化、消息线程真实卡死等情况都不会被盲目修改。

旧的周期 watchdog、主会话时间差推断、UIA 健康探针、定向重绑、强制重建、消息补扫和凌晨重置已经从运行时代码中删除。旧的总开关与新方案启用开关也一并移除；Windows 上的新监测随微信桥接固定启动。

## 2. 真实缺失监听的恢复

- 主应用从可信监听快照发现窗口确实缺失后，复用管理页面的正常添加监听入口逐个恢复。
- 每个聊天独立记录失败次数与下次尝试时间，采用 60–300 秒退避，避免持续故障时反复争抢微信界面。
- 窗口位置异常由 Win32 监测负责；窗口真实缺失由正常监听入口负责，两种情况不再混为一套破坏性恢复流程。

## 3. 群聊精确 `@` 发送

- API 单独传递成员名单，不再把 `@名字` 直接拼成普通消息文本。
- 微信主窗口中必须出现唯一的精确成员候选，并成功插入富文本提醒对象后才允许发送。
- 发送前会再次校验提醒对象数量和正文，失败时清空草稿且不自动重试，降低错发与重复发送风险。

## 4. 备份与迁移

- 备份列表新增永久删除操作；正在被待恢复计划引用的归档会受到保护。
- 完整迁移可通过 `SYSTEM_BACKUP_PPT_MASTER_DIR=wsl` 包含 WSL Codex 的 PPT Master 技能，状态备份不会包含该目录。
- PPT Master 恢复路径经过边界校验，并纳入原有回滚流程。
- 备份页面改为紧凑操作栏，集中展示类型、范围、创建、导入、刷新和删除操作。

## 升级说明

1. 更新后完整重启 Mabobot，使微信桥接和主应用同时加载新逻辑。
2. `WECHAT_LISTENER_WINDOW_WATCHDOG_ENABLED` 与 `WECHAT_LISTENER_WINDOW_AUTO_REPAIR_ENABLED` 已不再使用，可从旧 `.env` 中删除。
3. 如需调整窗口监测节奏，可使用 `WECHAT_LISTENER_WINDOW_AUTO_REPAIR_INTERVAL_SEC`、`WECHAT_LISTENER_WINDOW_AUTO_REPAIR_CONFIRMATION_PROBES` 和 `WECHAT_LISTENER_WINDOW_AUTO_REPAIR_RETRY_COOLDOWN_SEC`。
4. 只有需要迁移 PPT Master 时才配置 `SYSTEM_BACKUP_PPT_MASTER_DIR`；公开默认配置使用 `wsl`。

## 验证

- Windows 现场已验证异常独立窗口可在不重建微信窗口的情况下恢复。
- 窗口分类、连续确认、监听状态消费者、精确 `@`、备份删除与迁移路径均有专项回归测试。
- 发布前会对私有版和公开版分别执行语法、前端脚本及自动化测试检查。
