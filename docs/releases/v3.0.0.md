# Mabobot v3.0.0：迁移到 mabowx

Mabobot 3.0.0 完整替换微信 UI 自动化层，并同步升级助手、Codex 运行中心、模型路由、备份迁移和 Web 控制台。

## 升级重点

- 微信 UI 控制只使用项目内置的 `mabowx/`，不再安装或加载旧自动化库。
- 产品、环境变量、文件工具和运行目录统一使用 Mabobot 命名。
- 完整迁移备份必须使用 `mabobot-mabowx-backup` v2；旧代际归档不兼容。
- Codex 聊天默认按聊天隔离文件范围，只有显式授权的管理员私聊使用最大权限。
- 微信附件建立持久索引，可在后续消息中精确绑定并交给 Codex 处理。
- 控制台整合 Codex Profile、技能、系统工具、模型诊断和分层运行管理。

## 升级步骤

1. 先单独备份 `.env`、数据库和重要下载文件。
2. 更新全部源码与依赖，不要保留旧 UI 自动化包或兼容补丁。
3. 检查 `.env.example` 中的新命名，并迁移仍需保留的自定义设置。
4. 完整重启 Mabobot，确认 8888 与 5555 两个健康检查均正常。
5. 在 Web 控制台复核 Codex Profile、聊天监听和插件授权。

这是破坏性升级，不支持用 3.0.0 恢复旧格式备份。
