# Mabobot v2.2.0：统一运行、插件硬迁移与备份恢复

这次更新的重点不是增加零散功能，而是把经过多轮迭代后分散的运行、插件、Codex、存储和运维逻辑收回到统一平台。以后新增插件和后台能力可以直接接入同一套生命周期与管理界面。

## 更新亮点

### 1. 全部插件接入统一管理

- 当前发行版包含的内置插件已全部完成正式迁移。
- 旧 Runtime v1 和双参数 `register()` 不再提供加载路径，避免系统长期背负两套行为。
- 插件统一注册健康检查、清理钩子、后台操作、托管 worker 和标准存储。
- Weekly、JR 库存、中行汇率、飞书柜号等定时调度已纳入平台 worker 管理。
- 插件卸载或重载时，平台会取消其后台操作、发出停止信号并回收 worker。

这也成为后续插件的固定接入规范：新插件接入一次，就会自动获得统一的任务、数据、健康检查和资源回收能力，无需再为现有页面逐个适配。

### 2. Summary Plus 完成全阶段模块化优化

在不移除现有功能的前提下，Summary Plus 已从大型入口文件拆分出浏览器运行时、媒体管线、平台服务、任务准入和小红书处理等模块。功能保持不变，但维护边界、并发控制、资源清理和测试覆盖明显改善；它现在也是新插件的参考实现。

### 3. Codex 运行环境统一管理

- Codex 会话进入统一的运行时和有界并发管理。
- 支持查看版本、运行状态、活动会话、排队情况和错误信息。
- 管理页面新增一键升级，直接更新当前 Mabobot 使用的 Codex 运行环境。
- Codex 版本随全局环境升级，不再由各功能单独固定版本。

### 4. 新增备份、恢复与换机迁移

- “状态备份”用于日常保护配置、数据库、插件持久数据和生成结果。
- “完整迁移”额外包含当前代码，适合更换机器。
- 归档生成后可执行结构和文件哈希校验。
- 恢复前可自动创建安全备份，降低误操作风险。
- 插件数据现按持久数据、生成结果、缓存、机器绑定数据和临时文件分类，备份范围更清楚。

> 安全提示：当前版本按既定迁移策略直接备份 `.env`，归档尚未加密。请不要上传、分享或存放到不可信位置；加密归档将在后续版本加入。

### 5. 管理界面更紧凑

- 概览页直接显示系统、微信、插件、后台任务和运行时长。
- Codex 管理区重新排版，减少大卡片堆叠与空间浪费。
- 运行状态页面改为可折叠区块，并在折叠状态显示摘要。
- 运行状态按健康、当前任务、维护、问题和历史重新排序；原“高级设置”降级为最后一项“扩展设置”，只管理自定义键与导入工具。
- 存储扫描只更新局部进度，不再反复重绘整页，因此扫描过程中不会持续闪屏。
- 备份与迁移页面采用更简约的摘要、选项和结果布局。

## 升级前须知

1. 在“系统 → 备份与迁移”中先创建并校验一次备份。
2. 停止正在执行的摘要、报表、下载或 Codex 长任务。
3. 更新代码和依赖后重启 Mabobot；仅刷新浏览器不会加载新的后端运行时。
4. 首次启动会把旧插件数据迁入 `data/plugins/<插件>/` 标准目录。目标目录已有文件时以目标文件为准，不会覆盖。
5. 如果有自定义插件，请先按 `app/plugins/README.md` 升级到新版接入接口，否则插件会被明确拒绝加载。
